# Code of Conduct

This project adopts the Contributor Covenant, version 2.1, as its code of conduct. Everyone who takes
part in the project, in issues, pull requests, discussions and any other project space, is expected to
follow it. The full text is not copied here; read it at:

<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

The Contributor Covenant is licensed under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

## Reporting

To report unacceptable behavior, do not use a public issue;
contact the maintainer, [@ahwlsqja](https://github.com/ahwlsqja), through the contact method
on their GitHub profile and mark the message "Code of Conduct". Reports are handled privately, and the
reporter's identity is kept confidential as far as possible.

The maintainer has not yet published a dedicated conduct e-mail address; this file will name one when
it exists.
